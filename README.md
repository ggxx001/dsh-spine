# 脊髓（dsh-spine）

给 DeepSeek Harness 装的「本地手眼」：不用模型、不走 API、不花 token，就能看屏幕、找元素、点、打字、滚动。

对话模型看一眼截图要几千 token、来回一次几秒；高频重复的动作（点某个按钮、填某个框）走这套本地流程是毫秒级、零 token。

## 它是什么

- **看**：截屏 + 模板/元素匹配，返回元素坐标与置信度。
- **动**：真实鼠标键盘（Win32 SendInput），不是模拟事件。
- **刹车**：每步都过三层闸——STOP 停止标志、让位闸（人一动就让开）、判据（动作前后要有可观察的变化）。
- **学**：元素库 + 尝试记录，常用元素越用越准；不认识的新界面可以用 `learn` 学一个名字。

## 目录

| 路径 | 作用 |
|---|---|
| `脊髓统.py` | 主入口：动词分发（see / click / type / key / scroll / wait / learn / observe / find / hover / sheet / gate / status） |
| `脊髓.py` | 底层：截图、DPI 感知、元素定位、坐标换算 |
| `手眼.py` | 手眼协调：点完回读、失败重试、变化判据 |
| `弧.py` / `序列.py` | 反射弧与动作序列（把常用连招固化） |
| `反射服务.py` | 本地 HTTP 服务（默认 127.0.0.1:8811），给宿主插件调用 |
| `panel/服务.py` | 可视化面板服务（默认 8813） |
| `plugin/` | DSH 插件半边（把 `spine` 动词注册成工具） |

## 运行

```bash
python 反射服务.py          # 起本地服务 8811
python panel/服务.py        # 可选：起面板 8813
```

环境变量：

- `SPINE_BASE`：素材/元素库根目录（默认脚本所在目录）
- `SPINE_PY`：子进程用的 Python（默认当前解释器）
- `SPINE_DIR`：宿主插件找脚本的目录（默认插件目录的上一级）

只支持 Windows（依赖 Win32 截图与 SendInput）。

## 三层刹车

1. **STOP**：一个标志文件，出现即全部动作停手。
2. **让位闸**：检测到人在操作键鼠，立刻让开，人停手满若干秒才恢复。
3. **判据**：每个动作要有「动作后」的可观察证据（画面变化 / 元素出现 / 状态位），没有就算失败，不假装成功。

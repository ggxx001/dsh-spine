# 脊髓面板 接口契约（v1，冻结 2026-11-22 20:5x）

**一句话**：浏览器打开 `http://127.0.0.1:8813/`，看见当前窗口的实时截图 + 元素框，
点框就点屏幕；左边选动词，右边看回执与日志。

**进程**：`python 工具/界面反射/面板/服务.py` —— 常驻，stdout 打日志，端口 **8813**（默认，可用环境变量 SPINE_PANEL_PORT 覆盖）。
后台启动请用自己的守护脚本，不要挂在宿主 job 上。

**静态页**：GET `/` 返回 `面板/index.html`（同目录）。GET `/static/*` 返回 面板/ 下其他文件。

**通用回执**：所有 JSON 都带 `ok`(bool)。失败带 `why`(中文一句话)，不抛 HTML 错误页。

## 1. GET /api/health
```json
{"ok":true,"port":8813,"pid":1234,"engine":"脊髓统.py","stop":false,
 "gate":true,"service8811":true,"elements":335,
 "models":{"omni_icon":true,"ui_detect":true},"version":"1"}
```
- `stop`：急停文件 `界面反射/STOP` 是否存在（true = 所有动手动词已被引擎拒绝）。
- `gate`：让位闸是否放行（等价 `脊髓统.py gate` 的 ok）。
- `service8811`：常驻反射服务 8811 是否在跑。
- 要求：**≤150ms**（只读本地文件 + 可选短超时探测；不得为了这个接口去跑引擎子进程）。

## 2. POST /api/shot
请求 `{"window":"@fg"}`（`@fg`=前台窗口；也接受窗口标题片段；空=整屏）。
```json
{"ok":true,"ms":210,"png":"<base64 不含 data: 前缀>","w":1707,"h":960,
 "rect":[0,0,1707,960],"scale":1.0,"shot_kind":"window","window":"知鱼知乐 · DSH",
 "capture_path":"训练/ui-detect/shots/xxx.png"}
```
- `png`：截图（**含元素框画不画由前端决定，不要烘焙框**）。
- `rect` = [屏幕x, 屏幕y, 宽, 高]（**屏幕物理像素**，已含窗口 offset，和引擎 `box` 同一坐标系）。
- `scale` = 物理像素 / 截图像素（DPI 缩放；150% 时约 1.0 若截图已是物理像素，按实际算）。
- 前端换算：截图 uv 坐标 `(u,v)` → 屏幕坐标 `(rect[0]+u*scale_x, rect[1]+v*scale_y)`，其中
  `scale_x = rect[2]/w`、`scale_y = rect[3]/h`。**后端必须保证这两个比值成立**，若不成立就返回 500 并说明。
- 复用 `手眼.py` 的 capture 路径，**不要重新实现 DPI/offset 逻辑**。

## 3. POST /api/locate
请求 `{"kind":"input_box|overlay|icon","window":"@fg","want":20}`
→ 透传 8811 的 `/locate2`（kind 与 window）；8811 不在就退到 `脊髓统.py see --kind ... --window ...`。
```json
{"ok":true,"ms":240,"src":"8811","candidates":[
  {"box":[100,200,300,40],"score":0.93,"kind":"input_box","label":"地址栏"}
],"focus_rect":[..],"snapped":true,"window":"..."}
```
- `candidates[].box` 是 **屏幕物理像素** `[x,y,w,h]`，前端用 `rect` 换回 uv。
- 未命中时 `{"ok":false,"why":"..."}`，不要发明坐标。

## 4. POST /api/spine
请求 `{"verb":"click","args":{"x":120,"y":340,"--expect":"...","--window":"@fg"}}`
- `args` 的值全部拼成命令行参数：数字/字符串 → `--key value`；`true` → 只加 `--key`；`false/null` → 跳过。
- 执行 `python 脊髓统.py <verb> ...`，`timeout=180`。
```json
{"ok":true,"rc":0,"ms":812,"data":{ /* 引擎回执的 JSON 原样，可能为空对象 */ },"raw":"<stdout 尾部 2000 字>"}
```
- `ok` 判定：rc==0 **且** 回执里没有 `ok:false`/没有 `stopped:true`。（不准只信 rc）
- 动词白名单：status see icons find elements text settext click rclick dbl drag hover type key scroll arc seq observe wait gate sheet focus learn go。
- **不在白名单 → 400**，不许透传给 shell。

## 5. GET /api/arcs
```json
{"ok":true,"count":24,"arcs":[{"name":"钉钉发文件","steps":6,"desc":"..."}]}
```
来源 `弧.json`（键 `arcs`；每项字段以真实文件为准，缺的字段就别编）。

## 6. GET /api/logs?n=120
```json
{"ok":true,"lines":["11-22 20:40:12  RUN 钉钉/发文件 [dry]","..."]}
```
来源 `反射日志.txt` 尾部 n 行（默认 120，上限 500）。

## 7. GET /api/stats
```json
{"ok":true,"total":124,"ok_count":118,"rate":0.95,"ms_p50":412,"ms_p95":1180,
 "by_kind":{"click":{"total":60,"ok":57},"see":{"total":40,"ok":39}}}
```
来源 `训练/ui-detect/实验数据.jsonl`（每行 `{ts,kind,name,ok,ms,extra}`；坏行直接跳过）。

## 8. POST /api/stop
`{"on":true}` 建 `界面反射/STOP`；`{"on":false}` 删它。→ `{"ok":true,"stop":true}`

## 前端硬约束（赛博朋克操控台）
1. **单文件** `面板/index.html`，内联 CSS/JS，**零外部依赖**（不引 CDN、不引字体文件、不引框架）。离线可用。
2. 配色：底 `#05070d`、青 `#00f0ff`、品红 `#ff2e88`、琥珀 `#ffb020`、绿 `#39ff14`、警示红 `#ff3b3b`；字体 `Consolas, "Courier New", monospace`。
3. 布局三栏：**左=控制坞**（窗口选择 + 动词下拉 + 参数表单 + 执行 + 急停）｜**中=主画布**（截图 + 元素框叠加，hover 高亮描边，点击=click 该点并显示回执）｜**右=事件流**（回执 JSON 折叠 + 日志 tail + 统计条）。
4. 顶栏常驻状态：service8811 / gate / STOP / elements / models，异常项变红闪烁。
5. 视觉特效只用 CSS：扫描线、边框辉光、角标切角、数字流光。**不要 canvas 每帧重绘整页**（性能）。
6. 所有请求 3s 超时 + 错误必显示「为什么」（中文）。不许静默失败。
7. 点击画布 = 真点屏幕。所以：**按住 Shift 才允许点击生效**，左上角显示「SHIFT 已就绪 / 未就绪」；未按 Shift 只选中不点。
8. 首屏 ≤500ms 出骨架（先画界面再拉数据）。

## v2 追加（2026-11-22，脊髓控制台；v1 的 8 个接口语义未改）

新增只读/编排接口（同时服务于 `dsh-spine-console` 右栏插件，经 Host 同源代理访问）：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/trace?n=50` | `训练/ui-detect/trace.jsonl` 尾部 n 条，已转对象、倒序 |
| GET | `/api/trace/live` | 进行中的轨迹（`trace-live.json`），带 `age_ms`；`done:true` 表示上次已结束 |
| GET | `/api/snap?name=` | 失败快照 PNG；只允许 `fails/` 下的 basename |
| GET | `/api/plans` | `工具/界面反射/计划/*.json` 列表 |
| POST | `/api/plan` | `{sub:"run"\|"step", name, step?, dry?, keep-going?}` 跑计划 |
| POST | `/api/plan/save` | `{name, desc, steps:[{verb,args,note}]}` 写计划 |
| GET | `/api/arc?name=` | 单条固化弧完整 steps（`/api/arcs` 仍只给摘要） |
| GET | `/api/elements?q=&limit=` | 元素库条目摘要（含 disabled） |
| POST | `/api/element` | `{template, disabled}` 禁用/启用；首次写前自动备份元素库 |
| GET/POST | `/api/models` | 读/写 `模型开关.json`（`{set:{ui_detect:false}}`） |

### 变化与约定

- `/api/locate` 的候选新增 `src`（template/geometry/detector/uia_edit/ocr/focus_rect…）、`role`、`text`、`suspect`（UIA/CDP 来源为 true）。
- `/api/spine` 支持 `models`、`region` 两个动词；`region` 是纯图形区像素判据：`--save` 存基线，`--diff 基线 --tol --min` 比变化比例。
- 轨迹是**追加写**，超过 8MiB 自动滚到 `trace.1.jsonl`；失败才会截快照。
- 计划执行是逐步子进程，子轨迹带 `--trace-parent`；`STOP` 存在时 run/step 直接拒绝。
- 8813 仍不发 CORS 头；跨源访问由 Host 代理层 403。
